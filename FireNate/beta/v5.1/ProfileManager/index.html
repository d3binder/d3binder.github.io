Full raw backup

Downloads every single key FireNate has saved in this browser — your profile, every calculator's inputs, saved profiles, your theme choice, and every small on-page preference — exactly as stored, with no processing. This is a raw debugging/backup copy, not the same file "Export profiles" makes above — use that one (and "Import profiles") for actually moving your data to another device. Restoring one writes every key from the file straight back into storage, unprocessed — it can't be validated field by field the way "Import profiles" is, so only restore a raw backup you made yourself.
